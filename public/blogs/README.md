# 📸 How to Add Custom Generated Images to Your Blog

Every article generated by the AI automatically gets a **sleek branded dark-mode gradient banner** with category badges and typography out-of-the-box.

If you generate your own image (via Midjourney, DALL-E, Flux, Ideogram, etc.):

### Step 1: Save Your Image
Place your image file in the `public/blogs/` directory. For example:
`public/blogs/my-custom-cover.png` (or `.jpg`, `.webp`)

### Step 2: Link It in the Markdown File
Open the corresponding markdown file in `content/blogs/<slug>.md` and set the `coverImage` field in the frontmatter:

```yaml
---
title: "Your Article Title"
slug: "your-article-slug"
coverImage: "/blogs/my-custom-cover.png"
...
---
```

### Step 3: Add In-Article Images (Optional)
You can also insert images directly anywhere inside the article body using standard markdown:
```markdown
![Architecture Diagram of AI Workflow](/blogs/my-diagram.png)
```

Once committed or pushed to GitHub, Vercel will automatically re-deploy your site with the new image!
